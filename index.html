Jelaskan secara singkat pemahaman Anda mengenai perbedaan layanan berikut dengan mengisi kotak yang tersedia.

Shared Hosting

Layanan hosting yang menggunakan satu server secara bersama-sama dengan banyak pengguna. Biayanya murah dan cocok untuk website kecil.

Dedicated Server

Server fisik yang digunakan secara khusus oleh satu pengguna. Memiliki performa tinggi, kontrol penuh, dan sumber daya lebih besar.

Amazon Lightsail

Layanan cloud dari AWS yang menyediakan VPS dengan konfigurasi sederhana dan harga yang mudah diprediksi, cocok untuk pemula.

Amazon EC2

Layanan komputasi cloud dari AWS yang menyediakan server virtual dengan spesifikasi fleksibel dan dapat disesuaikan kebutuhan.
